## Projects

### [Text-to-SQL Query Agent](https://github.com/Praveen-bhadakambi/text-to-sql-agent)
Ask a question in plain English, get back a SQL query and its results.
- FastAPI backend with 9 endpoints, Groq LLaMA 3.1 for query generation, SQLite for storage
- Reads the database schema dynamically so the model always sees the current tables
- SQL safety validator that blocks 8 destructive operations and allows SELECT only
- Per-IP rate limiting, query history, CSV export, and a usage analytics endpoint

`Python` `FastAPI` `Groq` `SQLite` `Pydantic`

### [Resume Keyword Matcher](https://github.com/Praveen-bhadakambi/resume-keyword-matcher)
Compares a resume against a job description and scores how well they match. Built during my internship at SuprMentr.
- Combines TF-IDF with SentenceTransformer embeddings and cosine similarity
- Handles multiple resume file formats
- FastAPI service with a Streamlit front end

`Python` `FastAPI` `Streamlit` `SentenceTransformers` `scikit-learn`

### [URL Shortener](https://github.com/Praveen-bhadakambi/url-shortener-flask)
A Flask and SQLite URL shortener, built as part of my final-year coursework.

`Python` `Flask` `SQLite`
